## Этап 1 — Основа

**Что получает ученик:** открывает бота, жмёт «Открыть», приложение входит само, спрашивает цель и дату
экзамена, дальше — 5 вкладок на его языке. Вкладки пока с заглушками «скоро».

- Сервер на Go: проверка входа Telegram, пользователь создаётся при первом входе, профиль читается и меняется.
- База: таблица пользователей, миграции вшиты в сервер.
- Бот: `/start` отвечает кнопкой запуска Mini App.
- Интерфейс: онбординг (цель 4.0–9.0 с шагом 0.5, дата экзамена или «пока не знаю»), 5 вкладок, профиль
  с целью и языком, цвета из темы Telegram, uz/ru/en.
- Тест уровня — третий экран онбординга — появится в этапе 3; до тех пор онбординг из двух экранов.

**Выход из этапа:**
- `npm test` и `npm run lint` в корне зелёные;
- на настоящем телефоне: бот → «Открыть» → вход без пароля → онбординг → вкладки; смена языка;
  повторное открытие не показывает онбординг снова;
- первый экран — меньше 60 КБ JS (gzip, видно в `npm run build`).

## Этап 12 — Полный интерфейс

**Что получает владелец:** приложение, в котором видны и нажимаются все экраны продукта из SPEC — их
можно снимать для YouTube и показывать центрам. Данные на них придуманные, на каждом таком экране —
пометка «демо». Настоящими остаются вход, онбординг, профиль и Writing. Каждый следующий этап меняет
демо-данные своих экранов на настоящие.

- Онбординг: третий экран — тест уровня.
- Главная: «Турнир месяца» с обратным отсчётом, чемпион прошлого месяца, быстрый старт, новости.
- Экзамены: тест уровня, Reading и Listening (сет из 10 вопросов, результат), Writing (настоящий),
  Speaking (запись, разбор), полный mock (части, таймер, отчёт с Overall Band, план на 2 недели,
  карточка для сторис), история попыток.
- Рейтинг: Ташкент / мой центр / друзья / страна / центры; своё место внизу. Дуэли: вызов ссылкой,
  игра 5 минут, итог.
- Турнир: правила, части, расписание, прошлые победители.
- Сообщество: лента, мои группы и ДЗ, взаимная проверка эссе, правила сообщества.
- Новости: список и экран поста.
- Центр: страница центра, «присоединиться».
- Режим учителя: группы, работы с AI-черновиком, аналитика группы.
- Профиль: текущий и целевой балл, график прогресса, значки, Premium, бонусы за друзей, настройки.
- Ноутбук: вкладки слева, содержимое по центру.
- Фирменные цвета и знак, иконки, «до цели осталось», стрелки роста, карточки «поделиться» (отчёт,
  дуэль, турнир), заготовки вместо «Загрузка», плавные переходы.
- Анимация ожидания — пингвин-штангист (выбор владельца).
- Центры в демо — придуманные: настоящие названия только после согласия центра.

**Выход из этапа:**
- `npm test` и `npm run lint` зелёные — сделано;
- на телефоне в Telegram и в браузере на ноутбуке открывается каждый экран из списка, пометка «демо»
  видна — в браузере сделано; проверка в Telegram перенесена на этап 7 (решение владельца, DECISIONS);
- первый экран < 60 КБ JS — сейчас 41 КБ.

## Этап 2 — Проверка Writing

**Что получает ученик:** вкладка «Экзамены» → Writing → Task 2 (тема из банка или своя) или Task 1
(фото задания с графиком) → пишет ответ или фотографирует рукопись и правит распознанный текст →
«Отправить». Через минуту бот присылает балл, кнопка открывает разбор: балл по 4 критериям с
пояснением, ошибки «было → стало → почему», как получить на балл выше, исправленная версия.
3 проверки в день; неудачная не считается.

**Выход из этапа:**
- `npm test` и `npm run lint` зелёные — сделано;
- калибровка (`npm run calibrate`) на эссе **учителей**, включая 4–5 и 9 и несколько Task 1: среднее
  расхождение ≤ 0.5 и сдвиг в пределах ±0.25. Сейчас на 14 эссе с сайтов: 0.43, сдвиг −0.43 (DECISIONS);
- на телефоне в Telegram: Task 2 текстом, Task 2 фото рукописи с правкой, Task 1 с фото графика →
  сообщение бота → кнопка открывает разбор; черновик переживает закрытие приложения;
- вес JS < 60 КБ — сейчас 30 КБ.
