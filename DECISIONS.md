## 2026-11-15 — Стек: минимум памяти и максимум скорости

Ограничения: приложение открывается во встроенном браузере Telegram на недорогих Android через
мобильный интернет; сервер общий с ayzonstock (4 ядра, 5.8 ГБ); пик нагрузки — «Субботний Mock», когда
все одновременно ждут AI-проверку по ~10 с и играют дуэли.

| Слой | Выбор | Почему |
|---|---|---|
| Интерфейс | Svelte 5 + Vite + TypeScript, SPA без SvelteKit | Компилируется без тяжёлого рантайма (~10 КБ против ~35 КБ у Vue) |
| Стили | Свой CSS на переменных темы Telegram | Без фреймворка стилей: меньше кода, цвета берутся из темы Telegram |
| Telegram | `telegram-web-app.js` + тонкая обёртка `src/lib/telegram.ts` | SDK-библиотеки добавляют вес без пользы |
| Переводы | Свои словари uz/ru/en, `src/lib/i18n` | i18n-библиотеки тяжелее всего проекта на старте |
| Сервер | Go, стандартный `net/http` (маршруты Go 1.22+) | ~20–30 МБ памяти, тысячи одновременных ожиданий AI почти бесплатно, образ ~15 МБ |
| База | PostgreSQL + `pgx`, SQL руками | Без ORM и генераторов; sqlc не собирается под Windows без Docker |
| Миграции | Свой мигратор на `embed` (`backend/internal/db/migrate.go`) | Пара десятков строк вместо зависимости; миграции вшиты в бинарник |
| Бот | Внутри того же бинарника, Bot API напрямую по HTTP | Без отдельного процесса и библиотеки; webhook на сервере, long polling локально |
| Очередь AI-проверок | В PostgreSQL (River или своя таблица — решается в этапе 2) | Без Redis |
| Файлы | Cloudflare R2, загрузка с телефона по presigned URL | Байты аудио и фото не идут через сервер |
| Прокси | Существующий Caddy ayzonstock, отдельный блок поддомена | Порты 80/443 уже заняты им |

Цели по весу: первый экран — меньше 60 КБ JS (gzip); сервер в покое — меньше 50 МБ памяти; весь
compose-проект (сервер + PostgreSQL) — лимит 512 МБ.

Запасной вариант, если Go не подойдёт: Bun + Hono + Drizzle (TypeScript, ~60–80 МБ).

## 2026-11-15 — Вход через Telegram без сессий

Каждый запрос к `/api/` несёт `Authorization: tma <initData>`. Сервер проверяет подпись initData
(HMAC-SHA256, ключ из токена бота) и срок `auth_date` (24 ч) на каждом запросе — это микросекунды,
поэтому нет ни сессий, ни JWT, ни таблицы токенов. Пользователь создаётся при первом запросе.

## 2026-11-15 — Публичные данные отдельно от личных

Имя, фамилия и @username из Telegram хранятся, но **никогда не попадают в ответы о других людях**.
Публично — только ник, аватар и результаты (SPEC, «Безопасность»). Ник при создании генерируется
(`user12345`), ученик меняет его в профиле.

## 2026-11-15 — Тесты на настоящем PostgreSQL

Тесты сервера поднимают встроенный PostgreSQL (`fergusstrange/embedded-postgres`), как ayzonstock: не
нужен ни Docker, ни заранее установленная база. Первый запуск скачивает бинарники PostgreSQL в кэш.

## 2026-11-15 — База для разработки встроенная, без Docker

`npm run dev:db` (`backend/cmd/devdb`) запускает тот же встроенный PostgreSQL, что и тесты, с данными в
`backend/.devdb`. Docker на компьютере не нужен и часто не запущен. Кодировка задаётся явно (UTF8,
локаль C): на русской Windows initdb иначе создаёт базу в WIN1251.

## 2026-11-15 — TypeScript 6 в интерфейсе

svelte-check пока не поддерживает TypeScript 7 без второго компилятора рядом. Для проверки типов
разницы нет; вернуться к 7, когда svelte-check его поддержит.

## 2026-11-15 — Первые замеры (Windows, локально)

Сервер: бинарник 11.6 МБ, в покое 14 МБ памяти, после 2000 запросов по 50 одновременно — 59 МБ (Go
держит отданную память про запас; на сервере ограничим `GOMEMLIMIT`). Запрос `/api/me` с проверкой
подписи и базой — около 9 мс. Интерфейс — 21.8 КБ JS в gzip. Повторить замер в этапе 7 на сервере.

## 2026-11-16 — Проверка Writing: очередь, Gemini, балл

| Что | Решение | Почему |
|---|---|---|
| Очередь AI-проверок | Своя таблица `writing_checks`: воркеры берут строку `FOR UPDATE SKIP LOCKED` с арендой 2 мин, 3 попытки (пауза 30 с, 2 мин) | Двадцать строк SQL вместо River; проверка и задание — одна строка, история бесплатно. Упавший сервер — задание вернётся после аренды |

| Модель | `gemini-3.5-flash` | `gemini-3.8-flash` 2026-11-16 отвечала 503 и дольше 100 с. Смена модели — только с прогоном `cmd/calibrate` |

| Task 1 | Только Academic: фото задания с графиком, лежит в `writing_images` до конца проверки | Решение владельца; своего банка графиков до этапа 3 нет. Хранить фото дольше незачем до R2 (этап 4) |
| Лимиты до тарифов | 3 проверки и 10 распознаваний в день на ученика (по Ташкенту); неудачные не считаются | Решение владельца; защита от расходов до этапа 6 |

Промпт проверки (`ai.gradeInstruction`) меняется только вместе с прогоном калибровки — иначе неизвестно,
стало лучше или хуже.

## 2026-11-16 — Gemini только на платном тарифе

Бесплатный тариф ключа: 5 запросов в минуту и 20 в день — это меньше одной группы учеников. Кроме того,
по условиям Gemini API бесплатный тариф Google может использовать присланное для улучшения своих
продуктов, а это эссе школьников. На боевом сервере — только ключ проекта с включённой оплатой.

## 2026-11-26 — Файлы из базы отдаются кусками

Аудио Listening (до 15 МБ), скрины и фото лежат в `media.data`; сервер читал файл целиком в память на каждый
запрос, а телефон слушает аудио запросами Range по частям. С банком ~100 тестов десяток учеников на Listening
разом упирался бы в память контейнера (192–256 МБ — и на своём сервере, и на mars.cloud).

| Что | Решение | Почему |
|---|---|---|
| Отдача | `api/media.go`: размер — `octet_length`, содержимое — `substring` кусками по 256 КБ; в памяти — один кусок на запрос. Так отдают `/media/{id}` и `/api/admin/media/{id}` | Память не растёт с размером файла; база и файлы остаются в одном месте, копии — одна база |
| Хранение | `media.data` — `STORAGE EXTERNAL` (миграция 0021): без сжатия, `substring` читает из TOAST только нужное | Аудио, JPEG и PNG уже сжаты — сжатие базы их почти не уменьшает |
| Не выбрано | Файлы на диске контейнера или в R2 | Диск контейнера теряется при обновлении; R2 — ещё одна служба и копии отдельно от базы. Вернуться, если база вырастет больше, чем даёт хостинг |

## 2026-11-26 — Виды вопросов тестов канала и загрузка через админку

Тесты канала — HTML-тренажёры около 38 шаблонов (перетаскивание, выпадающие списки, «выберите два», карты,

| Что | Решение | Почему |
|---|---|---|
| Виды | Выбор (как раньше); `text` — вписать, верно при совпадении с одним из `accept`; `multi` — «выберите N»: вопросы группы делят верные буквы, каждая верная уникальная буква — балл, порядок не важен; буквы из общего списка группы — тот же выбор, тексты вариантов — в группе.
